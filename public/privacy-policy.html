1. Zero-Leakage Multi-User Tenant Vault Architecture

OmniGrab Pro enforces strict Zero-Knowledge Client-Side Tenant Isolation. When you use the Progressive Web App (PWA) or Chrome Extension:

  • Each device generates an isolated cryptographic key (usr_...) stored solely in your local browser sandbox.
  • Every database query is strictly scoped to your specific User ID (WHERE user_id = ?).
  • No user or administrator can view, inspect, or delete another person’s download history or bookmarks.
  • Multi-device synchronization between your personal phone and laptop requires explicit 6-digit Vault PIN pairing.

2. Automated 02:00 AM Midnight Storage Auto-Pruning

To keep the cloud database lightweight, ultra-fast, and completely bloat-free, an automated maintenance worker runs daily at 02:00 AM (UTC):

  • Deleted Daily: Ephemeral download stream logs (downloads_history older than 24h) and temporary media buffers.
  • PRESERVED FOREVER: Saved Bookmarks (saved_bookmarks), User Accounts & Vault PINs (user_vaults), and Application Preferences (user_settings) are never deleted.

3. Zero Third-Party Telemetry & Tracking

OmniGrab Pro does not contain Google Analytics, Facebook Pixel, tracking cookies, or external telemetry libraries. All network requests communicate directly and exclusively with your own self-hosted backend and private Turso LibSQL instance over TLS 1.3 encryption.

4. Chrome Extension Manifest V3 Permissions

  • activeTab: Sniffs media elements on the active tab only when explicitly clicked.
  • downloads: Triggers the browser's native saving mechanism to your local drive.
  • storage: Stores local preferences in local extension storage without external transmission.
  • contextMenus: Adds right-click options ("Download Media with OmniGrab").

5. Build & Code Ownership

The entire source code, build scripts, serverless functions, and extension packages are 100% self-hosted and owned by the deployment administrator. No central telemetry server or third-party entity controls or has access to your deployed build.
